# Aggregate source data

This directory contains aggregate manuscript source data that do not include transcript text.

Included categories:

- Tables 2 and 3 method/cohort metrics and paired contrasts;
- Figure 2 aggregate proxy summaries;
- Figure 4 performance and K-scaling summaries;
- Figures 5-7 method-level audit and utility summaries;
- aggregate inputs used by the locked manuscript analysis.

Excluded pending controlled-data review:

- transcript- or participant-level rows;
- candidate text or source text;
- raw embeddings or rows carrying controlled identifiers;
- individual prediction files.
